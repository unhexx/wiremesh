# Contributing to WireMesh

Спасибо за интерес к проекту!

## Процесс

1. Создайте issue с описанием предлагаемых изменений или бага.
2. Форкните репозиторий и создайте ветку от `main`.
3. Внесите изменения, соблюдая стиль кода (gofmt / black / prettier в зависимости от языка).
4. Добавьте/обновите документацию при необходимости.
5. Откройте Pull Request с понятным описанием.

## Стиль и принципы

- MVP first: сначала минимально рабочий функционал, потом красота.
- Документация должна жить рядом с кодом.
- Секреты и приватные ключи никогда не коммитятся.
- Предпочтительный язык для control plane и agent на старте — Go (один статический бинарь).
